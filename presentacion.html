TechStore

TechStore Inventario-venta

Versión 1.0

Visión

Ser una plataforma web de referencia para la simulación de compras de equipos tecnológicos, que permita a los usuarios consultar productos, administrar un carrito de compras y controlar su presupuesto de manera fácil, organizada y segura, promoviendo el uso de herramientas digitales para mejorar la experiencia de compra.

Objetivo General

Desarrollar un sitio web llamado TechStore que permita visualizar y seleccionar equipos tecnológicos, gestionar un carrito de compras y calcular automáticamente el valor total de los productos y el saldo disponible, utilizando HTML, CSS y JavaScript.

Objetivos Específicos o Principales

  1. Diseñar un catálogo digital que permita visualizar computadores e impresoras con sus respectivos nombres y precios.
  2. Implementar un carrito de compras que permita agregar, eliminar y consultar los productos seleccionados.
  3. Calcular automáticamente el valor total de la compra y el saldo restante del presupuesto inicial de $15.000.000 COP.
  4. Utilizar JavaScript y LocalStorage para gestionar y conservar temporalmente los productos seleccionados durante la navegación.
  5. Simular el proceso de compra y verificar que el valor total no supere el presupuesto disponible.
  6. Aplicar conocimientos de desarrollo web mediante el uso de HTML, CSS, JavaScript y Bootstrap.
